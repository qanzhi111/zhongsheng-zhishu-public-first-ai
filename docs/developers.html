📚 众生智枢开发者文档

🚀 快速开始

前置要求

Node.js

版本 18.0 或更高

Python

版本 3.9 或更高

Docker

最新稳定版

克隆项目

git clone https://github.com/qanzhi111/zhongsheng-zhishu-public-first-ai.git
cd zhongsheng-zhishu-public-first-ai

本地开发

# 方式1：使用Docker（推荐）
cd website
docker-compose up -d

# 方式2：手动安装
# 后端
cd website/backend
pip install -r requirements.txt
python main.py

# 前端
cd website/frontend
npm install
npm start

🤝 贡献指南

1. Fork项目

点击GitHub页面右上角的"Fork"按钮

2. 创建分支

git checkout -b feature/your-feature

3. 开发并提交

git add .
git commit -m "feat: 添加新功能"
git push origin feature/your-feature

4. 创建Pull Request

在GitHub上创建Pull Request，标题格式：
[feat/fix/docs]: 简短描述

请详细说明：
- 这个PR做了什么
- 解决了什么问题
- 测试了哪些场景
