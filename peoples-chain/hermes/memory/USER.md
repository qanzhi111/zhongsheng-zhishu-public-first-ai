# 用户偏好设置
# 众生智枢项目维护者偏好

## 交流偏好
- 语言: 简体中文
- 时区: 北京时间 (UTC+8)
- 响应时间期望: 24小时内

## PR审查偏好
- 小PR (<5文件): 快速审查，可自动合并
- 中PR (5-20文件): 标准审查流程
- 大PR (>20文件): 需详细讨论

## Issue处理偏好
- Bug报告: 优先处理，提供模板回复
- 功能请求: 评估后决定优先级
- 问题: 尽快回复，24小时内

## 代码风格
- 前端: React + TypeScript, 使用Vite构建
- 后端: Node.js + TypeScript 或 Python + FastAPI
- 格式: ESLint + Prettier
- 测试: 鼓励编写测试

## 自动化偏好
- 依赖更新: 启用自动合并（小幅更新）
- Issue stale: 60天无响应标记，7天后关闭
- PR stale: 30天无响应提醒，7天后关闭
- 欢迎消息: 自动发送

## 项目特殊要求
- 所有AI系统必须遵循"为民"原则
- 决策必须可解释、可审计
- 禁止任何形式的歧视性内容
- 保持项目文档更新
